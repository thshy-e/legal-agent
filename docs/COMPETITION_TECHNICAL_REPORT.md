# 劳法智枢技术报告初稿

适用：挑战杯大学生课外学术科技作品竞赛科技创新方向，供申报材料组织参考；具体分类与格式以学校正式通知为准。版本日期2026-10-25；内容以仓库产物为依据，尚非最终冻结稿。

## 项目解决的问题

劳动者通常提供零散事实，却难以将解除理由、劳动合同履行地、工资口径、证据持有情况和仲裁请求对应起来。通用问答可能遗漏条件，生成文书与测算金额也可能在多轮修改后不一致。本项目将工作重点放在维权准备过程的可追溯性和一致性。

首期用户为劳动者及协助整理材料的法律援助人员，地域重点为广州、深圳；其他七个大湾区内地城市提供全国与广东规则。核心请求为经济补偿、违法解除赔偿、代通知金和欠薪。实际港澳履行及复杂特殊用工进入专业复核。

## 技术机制与可展示贡献

1. **有职责边界的角色交接。** 沿用FastAPI和LangGraph，QA提供法源，Judge逐请求分析证据与反例，计算工具拥有金额，Review独立检查引用和条件，Doc消费当前确认对象。角色共享案件状态，SSE显示实际执行阶段。
2. **事实与法律判断分离。** 用户称违法不是认定；“没有考勤”是材料缺失。按解除类型列出专属条件，保留用户来源和确认状态，材料持有不等于真实性已核验。
3. **法源地域和版本控制。** 全国基础、广东及城市资料分层；精确法名条号、地域日期过滤、部分废止及适用冲突标记。最低工资和经济补偿封顶数据分用途；缺失口径不编造数值。
4. **可失效的计算与文书。** Decimal输出结构化计算对象；事实、地域、时间、知识或规则版本变化撤销旧金额、确认和文书。用户确认当前请求及金额后才生成草稿，过期确认409；文书一致性审查最多修订一次。

这些是当前工程机制的贡献，不等于提出新的通用多智能体算法。是否优于单Agent，需要真实对照实验和法律人工评分支持。

## 当前实现与数据

系统已有事实卡、逐期欠薪、地域覆盖说明、法源原文、官方链接、请求选择、修订记录、真实节点进度与Markdown草稿。索引为12份法规版本、2份指引、18条官方案例参考，共748条记录；6条地域参数中4条最低工资版本核验、2条封顶参数待核验。清单和快照可回退，不混用旧教学案例。专用向量接口已完成748条1024维向量构建及8项边界检查，默认仍保留词项模式，尚不宣称语义检索准确率。

新增6条深圳普通仲裁参考补充支持、不支持和举证不足方向，并保留历史规则变化限制。案例不等同于普遍规则，也未宣称18条均是生效法院判决。

## 验证设计及证据边界

工程验证覆盖地域/时间隔离、法名区分、否定表达、计算口径、条件门槛、请求互斥、过期确认、JSON重载、失败保留及文书一致性。当前自动结果与环境见 [验证记录](evaluation/casework_v2/validation.json)和[逐案工程结果](evaluation/casework_v2/engineering_results.json)。浏览器演示可复现欠薪7000.10元、修订为8000.10元并再次确认的闭环。

冻结工程集60案按20/10/10/10/10分组，公开可见，不能称盲测。v1文件保留；v2仅纠正三个零余额任务的“仍可确认零元请求”预期，输入及金额预期不变。不得用更正前后的通过率宣称模型能力提升。

真实模型实验固定Qwen-plus和采样配置，比较单Agent、协同无审查、协同有审查。统一提供原始输入和共享工具，不提供预期答案、评分或生产审查结果；记录调用数、实际模型、token、耗时和失败，接入地址亦进入续跑校验。这个实验衡量共享工具条件下的结构化决策，不能替代端到端体验研究。工作空间专用接口已完成60案三组实验，共180份结构化输出、360次成功调用；单Agent、协同无审查、协同有审查分别15、2、8组有自动标记。增加审查未在该指标上减少问题，不能宣称法律准确率或稳定协同收益。逐案记录和token、调用耗时见[实测报告](evaluation/casework_v2/MEASURED_MODEL_RESULTS.md)。前期鉴权及试跑失败保留为历史记录，未与本批混合。

法律准确性需依评分表人工逐案评定、严重错误单独统计。尚未取得教师/律师独立复审，也尚未开展独立盲测；不写“专家审核”“胜诉率提升”等结论。

生产办案流程另作有限验收：v11采用Qwen-plus分析与文书、Qwen3.8-Max审查，同一冻结欠薪案例连续3/3完成四阶段闭环，金额7000.10元修改为8000.10元后撤销旧确认与草稿；两个真实模型反例保持状态冲突与实际跨境履行的关键阻断。112项单元/集成测试及公开60案工程集通过。新配置改变了模型，不能与原三组全Plus实验混合统计，也不能据此归因于协同机制或宣称法律准确率。原始输出、失败历史及验证器规则码更正均见[验收记录](evaluation/casework_v2/LIVE_WORKFLOW_FINDINGS.md)。

历史v13另完成四阶段单次复测；10个扩展工程场景通过9项预期，其中足额支付场景不调用模型。剩余深圳历史欠薪因Judge引用适用问题被Review阻断，原始意见未自动降级。完整角色调用28次及逐案结果保留。

历史v14增加有条件的引用反馈修订：没有其他关键缺失或规则阻断时，将具体引用问题交回Judge一次，再独立Review；事实、条件、金额和确认受保护，前后分析与审查留档。受控回放v13引用问题后，2次真实新调用完成修订与复审；初审回放不算新调用。全新10场景8项严格工程预期通过，深圳历史欠薪完成分析及确认；另外两项分别因审查漏必填字段、长度截断导致首次调用元数据缺失而计失败。共有34次调用，其中1次缺完整用量，记录到的输入/输出token为170397/32194，不能作为总成本。冻结欠薪四阶段单次通过，196.609秒；119项工程测试及60案公开工程集通过。原始结果与限制见[扩展验收](evaluation/casework_v2/LIVE_SCENARIO_FINDINGS.md)。版本改变了生产协议，不能用前后通过数证明协同收益，引用适用仍待人工法律评分。

当前v15保持法律条件、金额和引用校验，格式纠正提供具体字段路径，SDK截断异常保留其实际返回的模型及用量。125项回归、公开60案及冻结欠薪四阶段真实调用单次通过（189.203秒）。全新10场景9项严格工程预期通过；剩余1项因90秒Review超时失败，仍阻止出稿。30次调用中1次超时无响应，已记录输入141735、输出25715 token，不能当完整成本。另一次非法律诊断主动限制16输出token，验证SDK截断异常保留46输入/16输出token、实际模型与length结束原因，并保持failed；不计入案件通过率。全部原始输出保留，版本间计数仍不构成协同收益或法律准确率证明。

已提供可填写的逐案复核包和CSV校验汇总工具，包含60份规则工程产物和180份真实模型产物；尚无实际人工评分。未运行模型输出不纳入评分，NA维度不进入得分分母，严重错误单列，填写人的身份与资质仍需另行核验。详见[人工复核操作](evaluation/casework_v2/LEGAL_REVIEW_WORKFLOW.md)。

## 项目简介

劳法智枢是面向劳动者与法律援助人员的劳动争议辅助系统。项目结合全国劳动法源、广东规则与广深城市资料，以事实澄清、法律检索、分请求分析、规则计算和交叉审查组织多角色协同，在用户确认后生成依据可追溯、金额可复核、材料相互一致的维权准备草稿。
