## 当前功能

劳法智枢面向劳动者及法律援助人员，使用全国基础法源、广东规则与广深城市资料，通过共享案件状态协调接待、检索、分析、确定性计算、审查及文书生成，提供依据可追溯、金额可复核的劳动争议准备草稿。

欠薪业务可完成事实补充、分期核算、用户确认、仲裁申请书草稿、材料清单及多轮修订。修改工资、日期或地区后，旧分析、确认和草稿失效；过期确认返回 HTTP 409。页面展示真实节点进度、事实来源、引用及审查历史。普通咨询保留独立入口。

v16 默认以自然聊天处理寒暄、概念、法条解释和多轮追问；普通答案不再自动展开完整案件报告。明确按本人情况计算、分析、修订或生成文书时才进入案件工作区。普通会话保存最近六轮实际问答，来源折叠展示；“第二点”“这一条”等指代无法确定时先澄清。案件中的材料解释为只读，唯一明确的工资期间修订才触发重算。

解除相关请求具备条件分析、互斥关系与公式输出。当前广深经济补偿封顶适用参数尚未核验，N/2N 金额确认被阻止，不能将这一链路描述为已经完整办结。跨境、2008 年前工龄及特殊用工进入专业复核。

## 启动与维护

在项目根目录执行：

```powershell
.\venv\Scripts\python.exe build_db.py --activate
$env:CASE_MODEL_ENABLED="0"
$env:LEGAL_VECTOR_SEARCH="0"
.\venv\Scripts\python.exe start_server.py
```

默认访问 <http://localhost:8000>。案件规则模式无需密钥，适合演示欠薪确认与修订。自然咨询的模型解释独立于 CASE_MODEL_ENABLED，仍需有效密钥；寒暄及精确法条可无模型运行。首次建立环境按 README 安装依赖；交付包不含虚拟环境、密钥、私有会话及生成索引。

真实模型模式需在本机 `.env` 配置有效的 `DASHSCOPE_API_KEY`、匹配工作空间的 `DASHSCOPE_BASE_URL`，并启用 `CASE_MODEL_ENABLED=1` 后重启。Judge/Doc 默认 Qwen-plus；本轮混合模型验收的 Review 使用 `CASE_REVIEW_MODEL=qwen3.8-max`。调用会产生费用，工程回归无需启用模型。JSON 会话存储用于单进程演示。

法源唯一入口是 `data/legal_sources/manifest.json`，当前 12 份法规版本、2 份指引、18 个官方出处案例参考，共 748 条检索记录；知识摘要 `b9b3767d4c14`。最低工资与经济补偿封顶参数分别管理。向量检索默认关闭，已验证构建和地域时间边界，尚未评价语义准确率。
