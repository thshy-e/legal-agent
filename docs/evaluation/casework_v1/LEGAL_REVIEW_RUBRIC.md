# 人工法律复核表

状态：待复核；未取得教师或律师独立审核，不得标为专家审核。60 个公开工程任务不替代独立盲测。

每个任务、每个对照组分别记录以下项目，`0=错误/遗漏，1=部分正确，2=正确且有依据，NA=不适用`。必须附错误说明及原始条文/案例链接，不能仅统计关键词。

| 维度 | 复核问题 |
| --- | --- |
| 事实与主张 | 是否保留否定、冲突、未知；有没有把用户称违法视为既定事实？ |
| 地域与时间 | 履行地/单位地是否澄清；版本及地方参数口径是否适用？ |
| 请求成立条件 | N、2N、第四十条代通知金、欠薪各自条件及证据是否齐全？ |
| 请求关系 | 是否错误累计 N 与 2N，或给第四十一条自动加代通知金？ |
| 证据与不利因素 | 是否编造持有材料；是否说明举证缺口与合理反例？ |
| 计算 | 工龄、工资口径、日期、最低工资、封顶及期间本金是否正确？ |
| 法源 | 是否可追溯、真实、现行/历史匹配；是否说明适用冲突？ |
| 确认与文书 | 是否当前版本确认；事实、金额、请求和证据目录是否一致？ |

严重错误单独计数：虚构法源、跨地域误用、废止条款当现行、无条件 2N/N+1、编造参数或证据、过期确认生成草稿、金额与文书不一致。严重错误不能被其他维度高分掩盖。

逐案记录字段：`task_id, variant, reviewer, reviewer_role, review_date, dimension_scores, applicable_dimensions, severe_errors, explanation, source_urls, final_legal_assessment`。无专家信息时 reviewer_role 写“内部核查”，不写“律师审核”。人工评分与程序的 `passed/automatic_errors` 分列，保留分歧和修订过程。
