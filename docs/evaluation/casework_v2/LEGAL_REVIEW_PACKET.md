## 1. 经济补偿封顶参数

运行库广州和深圳 severance_cap 仍为 pending。请分别核定：用人单位所在城市、解除日期、上年度工资统计指标、月工资数值、三倍后封顶值、公布及适用期间、官方原文与口径说明。参数值应直接保存“月工资三倍后的上限”，避免计算时再次乘三。

参考依据及尚不能解决的问题：

- [劳动合同法第四十七条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_0abfdd261c03417b949df19d869add8d.html)：规定用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资三倍，不能用最低工资代替。
- [深圳统计局2026-07-07答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3466400&via=pc)：指出现有多个平均工资指标，关于有关全口径数据业务可咨询人社部门。答复没有确认一个可直接作为本项目第四十七条上限的数值；也不能把“当时暂未计划公布”说成全年永远没有公布。
- [广州2025年平均工资统计](https://tjj.gz.gov.cn/stats_newtjyw/tjsj/tjgb/qtgb/content/post_10894378.html)已于2026-07-09公布，分别提供非私营、非私营在岗及私营口径；保存了官方快照，但统计发布本身尚不能证明本项目应采用的第四十七条指标及舍入方法。
- [深圳官方2025年平均工资页面](https://www.sz.gov.cn/cn/xxgk/zfxxgj/tjsj/tjgb/content/mpost_12907800.html)发布日期2026-07-24，现已成功保存快照，分别公布非私营就业人员191367元/年、非私营在岗职工193881元/年、私营99220元/年。此前统计局正文403与另一镜像TLS失败记录仍保留；新页面解决了正文资料获取问题，尚不能单独核定第四十七条指标及舍入方式。请求结果、快照哈希和未激活原因见 [研究记录](../../../data/legal_sources/severance_cap_research.json)。
- [深劳人仲案〔2023〕14951号、17601号](https://hrss.sz.gov.cn/ztfw/cjjy/wsgk/content/post_11219114.html)：个案使用2022年度月均13730元的三倍。它是历史裁决的计算背景，不能据此激活2025、2026参数或推定所有城市口径相同。
- [穗海劳人仲案非终字〔2026〕175-2号](https://www.haizhu.gov.cn/attachment/8/8018/8018922/10799846.pdf)：2026-01-07作出裁决，解除日期为2025-10-31；第6页在裁决理由中实际采用13704×3＝41112元上限，第8页裁决赔偿41112元。与2025-2926号的被申请人单方主张应区分。它不确立2026年解除的适用指标或全市统一规则；后续诉讼、生效状态未核实，原文在解除合法性表述上还有文字矛盾，保留原文待人工核查。
- [深圳税务2026年第5号通告](https://shenzhen.chinatax.gov.cn/sztax/xxgk/tzgg/202609/c6b762960af44d4c855d8cd0e58646b1.shtml)：已从原站保存正文。落款2026-07-31、网页发布2026-09-01，税款所属期自2026-07-01起。193881元是年度非私营在岗工资，16157元是该通告取整后的月工资；581643元属一次性补偿收入免税额，48471元属住房公积金/年金税前扣除工资上限。该用途及时间不能直接套作劳动补偿参数。

舍入并非无关紧要：广州2025在岗年均171731元，直接除以4为42932.75元，先将月均取两位再乘3为42932.76元；深圳193881元对应48470.25元，而税务取整后为48471元。以上仅为算术比较，不是本项目已认可的劳动法上限。复核时须明确所采用的指标、月均舍入步骤、三倍上限、适用解除期间和依据，不能只填写一个金额。

2026-10-26补查广深官方域名，发现的福田人社问答解释了工资构成与最低工资下限，未提供本项目所需的2026封顶值、舍入和适用期间；最低工资新通知仍是其他用途。该次检索没有取得足以激活的新增依据，不表示其他官方依据不存在。查询及候选页面见[补充检索记录](../../../data/legal_sources/severance_cap_search_20261026.json)，运行清单未改。

验收：官方依据应明确支撑所填口径及适用年度；记录核查人和日期、与现有最低工资用途隔离、重建索引、测试年度边界、重新分析并确认旧案。仅有网页金额或搜索摘要不够。

## 2. 解除条件及边界

| 规则 | 当前行为 | 需复核问题 |
| --- | --- | --- |
| 单位提出协商解除 | 追问是否达成一致 | 协商提出方、协议真实意思及撤销争议如何分支 |
| 第38条 | 追问具体事由、条件和解除理由送达；其他事由转专业复核 | 不足额社保等边界、地方历史口径、紧急解除不能一律套相同告知条件 |
| 第40条 | 区分医疗、不能胜任、客观情况变化；另核对保护情形与书面通知 | 培训/调岗、医疗期和另行安排、变更协商、工会程序及举证如何进一步结构化 |
| 第41条 | 要求法定规模事由、说明听取意见及报告程序陈述，不自动加代通知金 | 各程序具体要求、优先留用、再招用等是否与当前争点相关 |
| 第48/87条 | 违法仅为主张；继续履行请求与赔偿路径冲突时阻断 | 不能继续履行的事实及现行司法解释条件，不能由勾选代替裁审认定 |
| 欠薪 | 分期本金核对；零余额不开放追讨草稿 | 工资应得口径、合法扣除、时效与举证，不自动追加行政加付金额 |

[最高法对司法解释（二）的说明](https://www.court.gov.cn/zixun/xiangqing/472671.html)及库内第十九条可用于核对社保解除新规则。不得仅凭历史不支持案例否定现行法下的请求。
