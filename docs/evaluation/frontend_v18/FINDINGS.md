# v18 本地研发与验证（2026-10-28）

当前前端为v18研发版，后台仍为casework-20261026-v16 / conversation-20261026-v16。本轮只研发、运行本地前端与保存验证记录，没有生成新的交付压缩包。既有v17/v16包保留。

## 已实现

- 案件等待期间展示当前任务及已完成阶段，仅消费真实SSE事件。普通咨询仍用轻量等待状态；修订与复审不预设为必经阶段，无模拟进度百分比。辅助阅读器可接收实际节点开始提示。
- 审查问题按critical、warning、info排序，分别显示“阻止确认／待核实／补充说明”，文字、图标、色条并用。阻断项默认展开，提供核对事实入口；历史案件的操作入口停止使用。颜色不是败诉风险等级。
- 首页突出广深重点适配；案件摘要使用后端coverage，区分资料覆盖范围与实际检索来源。七市城市专项资料不足、地区未知及跨境边界不隐藏。
- 新案件缺少事实时默认三步填写，可切换全部字段。步骤只隐藏展示，不销毁字段；导航与刷新保留工资期间及隐藏的解除条件，包括false。只有明确保存才提交分析，保存和确认仍分离。
- 来源面板根据回答中真实引用标记返回原消息位置，突出对应段落并返回键盘焦点；手机上关闭详情再返回。不为仅检索到、未出现引用标记的来源构造支持关系。来源存在不代表其支持整段结论。
- 当前有效、确认和文书版本一致且无关键阻断的草稿显示材料准备摘要：已确认请求、金额、公式、待补材料、主体占位及专业复核提示。未保存编辑、案件操作、409或中断待同步时立即暂停摘要及旧稿复制。历史结果只读，不称“结案”，不显示专家背书。

公共API、法律事实字段、计算、确认及后端规则不变；页面新增状态只存会话ui。旧active-session键与会话存储兼容保留。后端40个Python文件的整体SHA256对比见validation.json。

- browser-failures.json记录19项异常与边界检查：独立真实请求触发HTTP409、显式同步不确认、历史只读、普通网络失败保留有效案件、迟到实际响应隔离、跨境阻断、东莞覆盖边界、无标记不构造引用上下文、焦点约束和减少动态效果。

- 控制台出现2条预期资源错误：一次真实409、一次主动注入ERR_FAILED；没有将其写成零错误。未观察到其他JavaScript异常。
- 1440×1000、1024×900、390×844均无页面横向溢出。修复了辅助阅读器隐藏提示造成的外层多余滚动条。窄屏、焦点与剪贴板验证不能代替实体手机软键盘或放大体验。
- browser-citations.json额外验证仅真实引用标记生成按钮、未知标记和代码内容不被绑定、脚本被过滤，以及外层无溢出；最终源码重新验证了引用返回与焦点。browser-edits.json验证未保存时明确标注旧测算、停用复制，放弃编辑恢复摘要且不提交。原始解释性追问见live-explanation.json。汇总与源码哈希见validation.json。

普通材料解释在实际Qwen服务下返回并保留有效案件；本轮只保存浏览器交付内容，不新增完整模型用量遥测，不推算调用数、token或法律准确率。完整流程脚本曾因原生离页保护暂停，处理后完成；增加自动接受测试中的beforeunload后重新执行并保存最终报告。脚本调试不作为应用成功证据。
