## 3 源码、依赖与运行入口

（1）运行总入口：`README.md`、`start_server.py`、`build_db.py`、`requirements.txt`、`requirements-win-py312.snapshot.txt`。默认浏览器地址`http://localhost:8000`，具体命令见配套运行说明第2章。

（2）前端v18：`frontend/index.html`、`frontend/workspace.css`、`frontend/workspace.js`、`frontend/casework.js`。后台API：`legal_ai_agent/api/server.py`。

（3）案件工作流与角色：`legal_ai_agent/casework/workflow.py`、`roles.py`、`model_policy.py`。字段、提取与校验：同目录`models.py`、`facts.py`、`fact_checks.py`、`evidence.py`。

（4）法源、条件和计算：同目录`knowledge.py`、`conditions.py`、`calculation.py`。审查反馈：`review_grounding.py`、`review_revision.py`。法源数据入口：`data/legal_sources/manifest.json`；索引构建：`legal_ai_agent/rag/build_db.py`。

（5）测试入口：`tests/`、`tests/frontend_workspace.test.cjs`、`scripts/run_case_evaluation.py`及`scripts/README.md`。新文档图件与正文生成脚本：`scripts/build_contest_submission.py`，属于材料制作工具。

（6）配置示例采用占位符。实际`.env`、密钥、本机私有会话及虚拟环境不纳入参赛书面交付。原始公开实验使用合成任务，与个人案件数据分开。
