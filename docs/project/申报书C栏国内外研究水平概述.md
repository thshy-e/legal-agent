# C 当前国内外同类课题研究水平概述

（1）国内研究与应用进展

我国法律人工智能研究已由知识问答扩展到法律推理、知识增强和多角色协作。LawBench以20类中文法律任务，从知识记忆、理解和应用三个层面评价大模型，为研究不同法律能力提供了共同任务基础。[1]Chatlaw的2026年修订研究模拟法律服务中的助理、研究与分析等职责，以角色对齐的混合专家结构支持协作，体现了法律专业分工与模型技术结合的发展路径。[2]通义法睿等产品已形成咨询、法规和类案检索、案情分析、文书生成与合同审查等能力，推动法律模型向实务应用转化。[6]

国内研究还在推进从对话到复杂任务的衔接。2026年10月发布的LawCompass将法律问答、专业检索和多智能体深度研究统一组织，并在模块之间保留显式引用关系。[5]相关工作表明，法律AI正在从回答单个问题，向围绕来源、步骤与完整产物组织服务发展。面向劳动者的具体应用，需要进一步把这些能力与地域规则、事实补充及工资核算结合。

（2）国外研究与产业发展

国外已形成专业法律内容平台、生成式助手与工作流结合的应用格局。LegalBench由法律与计算机领域人员协作构建162项法律推理任务，强调从具体任务观察模型能力。[3]L-MARS的2026年修订研究将智能检索、多角色处理与引用支持性审查相结合，逐项核查论断与所引来源的关系，使评价从答案本身扩展到依据质量。[4]

产品方面，Harvey以对话、资料库和工作流组织研究、分析及起草，支持答案与来源连接。[7]2026年版CoCounsel Legal依托Westlaw与Practical Law等专业内容，将研究、论点分析、文书起草和核验置于连续环境，保留专业人员对论点和决策的控制。[8]国外代表产品已具备较成熟的专业内容与工作环境，发展重点正在向任务编排、产物核验和案件上下文管理推进。

（3）同类课题的发展趋势

现有研究与产品呈现三个方向：一是检索增强与专门法律资料结合，使回答具备可阅读、可定位的来源；二是以角色分工和工作流承接多步骤任务，衔接分析与起草；三是将人工参与、引用审查和任务评测纳入交付过程。[1—8]面向具体地区和业务，关键在于把这些方法落实到实际输入、法源适用、确定性数值及产物变更的完整数据链条。

劳动争议准备既包含语言理解，也包含日期、工资口径、请求关系和材料状态等明确条件。其专业要求不仅体现在回答的完整程度，还体现在事实修订后算式、金额与草稿能否同步更新。这为面向劳动者的垂直系统提供了清晰的技术研究对象和应用空间。

（4）本作品的研究定位与特点

劳法智枢以广州、深圳劳动争议材料准备为重点，将全国基础法源、广东规则和城市资料结合，以共享案件状态连接接待、检索、分析、确定性计算、审查与文书。其特点是自然咨询与渐进核对衔接，法源先按地域时间筛选，金额由规则工具生成，用户确认绑定当前版本，事实修改触发旧金额、确认和草稿联动失效。

作品已实现欠薪核对、草稿生成及多轮修订闭环，保存146项Python回归、60案工程任务和三组真实模型实验等记录。项目将法律AI的研究、检索和起草能力落实到可核对、可计算、可更新的材料准备流程，形成面向劳动者及辅助人员的场景化工程成果。后续将通过城市参数完善、法律专业评价和真实用户试用，继续推进区域扩展与服务应用。
