录制日期：2026-10-25。文件：[contest-casework-demo.webm](contest-casework-demo.webm)。约2分17秒，1440×1000，VP8，15fps，无配音。

连续流程：

1. 广州欠薪案件：输入履行地、单位所在地、争议日期，以及“没有考勤，有工资流水”。补充2026年9月工资应付8000.10元、实付1000元。
2. 确认7000.10元请求，生成对应金额的仲裁申请书草稿，主体信息保留占位。
3. 将应付改成9000.10元；旧确认和文书失效，再次确认后生成8000.10元新稿。
4. 分别精确查询劳动法、劳动合同法第四十七条，展示法名区分及普通咨询与前案金额隔离。

核查：浏览器控制台0条错误/警告；视频12秒、65秒、120秒处解码截图已目视检查，分别看到事实澄清、7000.10元草稿、8000.10元修订稿。检查范围为关键帧及页面操作断言，未进行逐帧或音视频完整质量检测。摘要和文件SHA256见 [验证记录](../../docs/evaluation/casework_v2/validation.json)。

演示不含真实劳动者资料，不证明证据真实性，也未开展专家审核。广深经济补偿封顶参数待核验，本录屏仅演示欠薪闭环。最终答辩需按 [6分钟脚本](../../docs/DEMO_SCRIPT.md)补充讲解、法律边界及实验结果；该文件不是最终提交视频。
